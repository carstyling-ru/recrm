# RECRM — прототип сайта

Сайт доступен всем по адресу **https://carstyling-ru.github.io/recrm/**.

17 экранов в основной последовательности, четыре статьи блога, выдвижное меню, вертикальные переходы и адаптивная верстка. После блога прокрутка открывает завершающую форму бесплатного доступа. Статьи открываются из блога и исключены из общей последовательности экранов. Форма демонстрационная: данные не отправляются и не сохраняются на сервере.

В блоге показаны анонсы четырёх реальных статей RECRM: о [мобильном приложении](https://recrm.ru/blog/206/), [воронке продаж](https://recrm.ru/blog/190/), [конкурентных преимуществах](https://recrm.ru/blog/154/) и [выборе CRM](https://recrm.ru/blog/152/). Оригинальные изображения сохранены; колонки новостей и дат публикации нет. Анонсы и полные тексты доступны на русском, английском и грузинском. Ссылки в статьях открывают форму бесплатного доступа на выбранном языке.

Все статьи используют единый макет: заглавная иллюстрация слева и текст справа, на телефоне — одна колонка. Ссылка «Все статьи» находится над заголовком, переходы к предыдущей и следующей статье — под содержимым. В статье о воронке продаж используется иллюстрация из анонса `190.png`; пять скриншотов внутри текста сохранены.

Адреса статей: `#mobile-crm-guide`, `#sales-funnel`, `#competitive-advantages`, `#choosing-crm`. Данные находятся в `content.json` → `articles`, маршруты — в `app.js` → `articleRoutes`.

`#advertising`, `#customers`, `#geography` и `#support` пропускаются при последовательном просмотре во всех языках. Их содержимое и прямые ссылки сохранены. Для возврата страницы удалите её slug из `sequenceExcluded` в `app.js`. Пункт «Поддержка» скрыт в меню атрибутом `hidden` у ссылки `href="#support"` в `index.html`.

Кнопка бесплатного доступа находится внизу справа вместо чата. Вверху справа работает выбор «Русский / English / ქართული». Переводятся экраны, статья, меню, FAQ, формы и сообщения. Язык сохраняется в браузере; смена языка не перезагружает страницу и сохраняет данные формы и состояние открытых блоков.

Прямые ссылки: [English](https://carstyling-ru.github.io/recrm/?lang=en#intro), [ქართული](https://carstyling-ru.github.io/recrm/?lang=ka#intro), [Русский](https://carstyling-ru.github.io/recrm/?lang=ru#intro). Язык ссылки имеет приоритет над сохранённым выбором. Содержимое исходных скриншотов интерфейса, видео и внешних сайтов остаётся на языке оригинала; тарифы указаны в рублях. На первом экране используется название `RECRM.online` и отдельные цены для языков: `345 ₽` (RU), `$4` (EN), `10GEL` (KA). В демонстрационной иллюстрации `#crm-comparison` используются локальные примеры адреса и валюты: High St и фунты для английского, улица Шардени и лари для грузинского.

Переводы находятся в `locales/{ru,en,ka}.json`, механизм — в `i18n.js`. Шрифт Noto Sans Georgian распространяется по SIL OFL; текст лицензии включён в `assets/`.

GitHub Pages публикует корень ветки `codex/github-pages`. Для обновления сайта замените статические файлы в этой ветке и отправьте коммит в GitHub.

Для локального просмотра: `python3 -m http.server 4173`, затем откройте `http://localhost:4173/`.
