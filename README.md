# RECRM — прототип сайта

Сайт доступен всем по адресу **https://carstyling-ru.github.io/recrm/**.

21 экран в основной последовательности, статья блога, выдвижное меню, вертикальные переходы и адаптивная верстка. После блога прокрутка открывает завершающую форму бесплатного доступа. Статья открывается из блога и исключена из общей последовательности экранов. Форма демонстрационная: данные не отправляются и не сохраняются на сервере.

Кнопка бесплатного доступа находится внизу справа вместо чата. Вверху справа работает выбор «Русский / English / ქართული». Переводятся экраны, статья, меню, FAQ, формы и сообщения. Язык сохраняется в браузере; смена языка не перезагружает страницу и сохраняет данные формы и состояние открытых блоков.

Прямые ссылки: [English](https://carstyling-ru.github.io/recrm/?lang=en#intro), [ქართული](https://carstyling-ru.github.io/recrm/?lang=ka#intro), [Русский](https://carstyling-ru.github.io/recrm/?lang=ru#intro). Язык ссылки имеет приоритет над сохранённым выбором. Содержимое исходных скриншотов интерфейса, видео и внешних сайтов остаётся на языке оригинала; цены указаны в рублях.

Переводы находятся в `locales/{ru,en,ka}.json`, механизм — в `i18n.js`. Шрифт Noto Sans Georgian распространяется по SIL OFL; текст лицензии включён в `assets/`.

GitHub Pages публикует корень ветки `codex/github-pages`. Для обновления сайта замените статические файлы в этой ветке и отправьте коммит в GitHub.

Для локального просмотра: `python3 -m http.server 4173`, затем откройте `http://localhost:4173/`.
